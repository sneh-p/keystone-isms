# Change Management Policy

- Changes to production systems, network devices and cloud configuration are recorded, assessed for risk and approved before they are made.
- Standard, low-risk changes can be pre-approved. Emergency changes are approved afterwards within one working day.
- Changes are tested before release and can be rolled back.
- Secure baseline configurations are kept for key systems, and drift from them is detected and fixed.
