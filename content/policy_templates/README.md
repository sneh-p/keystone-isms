# Policy templates

Original Keystone content. Each file has YAML front matter (`code`, `title`, `type`,
`controls`, `acknowledge`, optional `when`) and a Markdown body. Placeholders:
`{{company}}`, `{{isms_owner}}`, `{{scope}}`, `{{review_months}}`, `{{year}}`.
The onboarding wizard fills them in and creates draft versions for review and approval.
These are starting points: adapt them to how your organisation actually works.
